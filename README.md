# claude

This repository hosts **local-dev-mcp** — a local Model Context Protocol (MCP)
server that gives Notion AI (or any MCP client) Claude Code-style access to the
local machine: filesystem, terminal, git, project analysis, processes, network,
databases, containers, archives, editor integration and GUI automation.

See [`local-dev-mcp/`](local-dev-mcp/) for the project, its documentation and tests.
